## General info
This is my music prototype made in TunePad using Python, which uses eight separate cells to build an instrumental composition inspired by relaxed hip-hop artists jazz influences, such as MF DOOM and Nujabes. The project explores how code can control rhythm, notes and the timing of different musical parts.

The saved project settings are **96 BPM** and **4/4**.

**Important Note:** On 19 October 2026, my laptop broke and I had to replace it. When I returned to TunePad, I had lost all progress on the web broswer, but had kept copies of my code in the Notes app, so I was able to re-enter the saved code into a new project. The current project’s creation date reflects that later transfer.

## Technologies

- **TunePad** — the browser/environment used to edit and play the project.
- **Python** — the language used in the music cells.
- **TunePad music functions and instrument presets** — some basics including `playNote`, `moveTo` and `rest`.
